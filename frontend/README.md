# Frontend Dashboard

The frontend is a Next.js application that provides a dashboard for monitoring synthetic browser sessions, workers, and jobs.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Features

- dashboard summary cards
- job list and status tracking
- worker health table
- simple UI for viewing the current test environment

## Stack

- Next.js 14+
- React
- TypeScript
- Tailwind CSS-ready structure

## Notes

This project uses a lightweight starter dashboard so the repo can be extended to include authentication, analytics, and worker management screens.
