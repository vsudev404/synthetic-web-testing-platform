## Start with one command (added)

To start the full stack with one command, you can use the Makefile or the provided scripts.

- Linux/macOS: `make start` or `./scripts/start.sh`
- Windows PowerShell: `./scripts/start.ps1`

These will copy `.env.example` to `.env` if needed, build the images, start containers and wait for the backend to be healthy.
